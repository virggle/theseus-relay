# 定位 · 与近亲架构的边界

**中文** | [English](POSITIONING.en.md)

> 忒修斯号不是凭空发明的。它和几支已知流派解决的是同一个问题的不同切面——**上下文腐烂（context rot）**：长会话随上下文填满而变贵、变蠢、忘事。本文说清楚我们和它们各站在哪里，以及从谁那里抄了什么。

## 一句话定位

**Ralph Loop 解决"任务一口气做不完"，忒修斯号解决"对话聊着聊着变蠢"。** 两者的核心赌注相同——新鲜上下文 + 状态外置 > 单会话无限膨胀——但记忆载体的哲学相反：Ralph 说"磁盘即状态"，忒修斯说"语言压缩物即状态"。v0.3 基底化之后，两者在"disk is state"上收敛。

## 各自的真贡献

- **Ralph Loop**：证明了"裸循环 + 磁盘状态"的暴力可用性。它最值得抄的不是循环，是**纪律的安放位置**——规则放 harness 不放 prompt、状态放磁盘不放模型、失败模式（迭代/成本/时间上限）全部可观测。
- **`/compact` 类 compaction**：定义了问题（上下文会烂），但把压缩当副作用。忒修斯的增量：**把 compaction 从副作用提升为协议级一等公民**——schema、只增不删的决策账本、反占位符、机械校验，全部用来驯服压缩质量方差。
- **Multi-agent handoff**：传递的是原始上下文或自由文本，没有"上一棒死了、只留一份压缩物"的强语义。忒修斯的不变量"简报是唯一传输介质"严格得多。
- **LangGraph checkpointer**：状态外置思想同源（执行者无状态、状态持久化），但所有状态平权。忒修斯明确了丢弃时的牺牲顺序（进展 < 开放问题 < 画像 < 决策），并给决策账本"最神圣"地位——它是协议的免疫系统。

## 从 Ralph 抄走的（已落入协议/路线图）

1. **确定性 backpressure**（ROADMAP v0.2）：质量门（测试/lint/build）先于 LLM 审查棒。零 token、零偏见、每次必跑。
2. **规则下沉到基底**（PROTOCOL §4 校验器）：反占位符从提示词级降为脚本级——决策/画像条目数不得减少，基底 diff 即可拒收。
3. **不变量与易变态分离**（Ralph 的 PROMPT.md 从不参与压缩）：协议、落盘决策不进有损压缩流，简报只携带指针 + 增量。
4. **可观测的失败模式**（ROADMAP v0.2 预算与震荡检测）：棒数/成本上限 + 决策震荡检测——同一方案被否了又被重提，等价于 Ralph 的循环往复，可机械告警。

## Ralph 给不了、必须自己建的

- **简报 schema 校验器**：Ralph 没有传输协议，也就没有校验问题。我们的校验器是棒级事务的 commit 条件。
- **压缩质量度量**：定期用「基底原文 vs 当前简报」做召回抽查，把长程衰减从诚实清单里的一句自白变成可观测指标。这是 prose 记忆路线相对 disk 路线的固有税——Ralph 永远不用交，所以没有现成作业可抄。

## 关系总结

Ralph 是"让循环跑下去"的暴力美学，忒修斯是"让每一次换棒不丢魂"的协议工程。后者更难；也正因为难，如果做成，跨模型接力的成本调度（v0.5）是裸循环给不出的能力。
